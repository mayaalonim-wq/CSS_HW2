# CSS Homework 2 – Responsive Layout

This project was created for Homework 2 in the Web Programming course.

The assignment includes 4 different HTML pages, all using the same layout but built with different CSS techniques:
- Plain CSS (manual)
- Plain CSS generated by Copilot
- Flexbox version generated by Copilot
- Bootstrap version generated by Copilot

---

## Website Link (GitHub Pages)

You can open the full website here:  
https://mayaalonim-wq.github.io/CSS_HW2/

The **index.html** page includes links to all four layout versions:

1. **Manual Plain CSS** – manual_plain.html  
2. **Plain CSS (Copilot)** – plain_ai.html  
3. **Flexbox (Copilot)** – flex_ai.html  
4. **Bootstrap (Copilot)** – bootstrap_ai.html  

---

## Responsiveness

All pages were tested and work on both desktop and mobile devices.  
The site opens from the README link and allows navigation to all 4 pages.
